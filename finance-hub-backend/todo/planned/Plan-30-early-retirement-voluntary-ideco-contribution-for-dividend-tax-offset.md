# Plan 30：未滿60歲提早退休（FIRE）支援自主繼續提繳iDeCo——利用小規模企業共済等掛金控除沖銷股票配當所得，實現退休後退稅最佳化

## 這份計畫怎麼來的
這是在討論[issue-193](../pending%20fix/issue-193.md)（退休當年iDeCo提繳被整年錯誤歸零、判定依據混淆）時衍生出來的進階功能需求。在探討「退休與提繳是否該直接綁定」時，使用者提出核心商業洞見：**「沒薪水的人依然可以提繳iDeCo，例如股票配當多的FIRE族，可以用iDeCo掛金來沖銷股息所得節稅」**。

現行模擬引擎為了簡化設計，原則上假設「退休（`isRetired`）＝停止投入新資金」。這對60～65歲正常退休的使用者完全足夠，但對於40～50歲提早退休、以高配息股票資產維生的高資產FIRE族群，無法模擬其在60歲前繼續自主提繳iDeCo所帶來的確定申告退稅效益。這份計畫將這個進階規劃獨立立案，與Issue 193的核心Bug修復解耦。

## 真實世界稅法與業務機制

### 1. 提早退休者的iDeCo法定加入資格
- 日本居民在20歲以上、未滿60歲期間，若提早退休離職（喪失厚生年金第2號被保險人資格），會自動轉為**國民年金第1號被保險人**（自營作業者／無職）。
- 只要按規定繳納國民年金基礎保險費（未申請全額免除），**依法完全具備繼續提繳iDeCo的法定權益**。
- 而且提繳額度上限會從上班族的每月1.2萬～2.3萬日圓，**大幅提升至每月最高6.8萬日圓**（每年最高81.6萬日圓）。
- 提繳款項由個人銀行帳戶扣款，與原雇主完全脫鉤。

### 2. 股票配當所得（股息）與iDeCo的退稅連動機制
- 上市股票配當在發放時通常會被預先扣繳20.315%（所得稅15.315% + 住民稅5%）。
- 提早退休者若無薪資工資，但有大量股票配當：
  - 可於次年春季辦理**確定申告（選擇「総合課税」）**，將股息併入總所得。
  - iDeCo全額提繳額依法享有**「小規模企業共済等掛金控除」**（100%全額所得扣除）。
  - 當年度已繳之iDeCo扣除額（最高81.6萬）＋基礎扣除等，可直接沖銷股息課稅所得。
  - 沖銷後，國稅局會將當初在券商被溢扣的配當預扣所得稅，**以現金還付金（退稅）形式全額退還至個人銀行帳戶**。

## 針對什麼問題
1. **現狀強制假設「退休即斷繳」**：在退休發生後，系統會直接關閉提繳通道，使得未滿60歲的FIRE使用者在模擬中無法繼續累積iDeCo資產。
2. **缺乏退休後自費提繳的現金流與稅務通道**：目前iDeCo提繳被視為工資扣繳的一環；當薪資歸零時，系統欠缺「從流動現金（銀行帳戶）主動扣繳iDeCo、並在確定申告產生退稅」的端到端管道。

## 建議架構與系統設計

### 1. 資料模型擴充（`UserProfile`）
在使用者財務檔案中，新增一個非必填的進階開關：
- **`continueIdecoUntil60IfEarlyRetired`**（`Boolean`，預設為 `false`）：
  - 語意：*「若在60歲前提早退休，是否繼續提繳iDeCo至60歲法定上限」*。
  - 僅在 `targetRetirementAge < 60` 且使用者有啟用iDeCo時生效。
- **`earlyRetirementMonthlyIdecoContribution`**（`Long`，選填）：
  - 語意：提早退休後的每月提繳額度（預設可沿用在職月額，或由使用者自行設定，上限為第1號被保險人的68,000円）。

### 2. 前端 UI 呈現（`hub-ui`）
在 `ProfileContributionsSection` 的 iDeCo 設定區塊中，以條件式展開（Conditional UI）方式提供：
- 僅當使用者的 `targetRetirementAge < 60` 時，才於介面顯示此切換開關（避免干擾一般60～65歲正常退休的絕大多數用戶）。
- 附帶 Help Text 說明：「啟用後，退休後至60歲前將自流動現金持續扣繳iDeCo，並可於確定申告抵扣配當或其他所得」。

### 3. 計算引擎串接（`TaxAdvantagedAccountProjector` & `YearlySimulationPipeline`）
- **提繳判定**：
  若 `age < 60` 且 `context.isRetired()` 為 true：
  - 若 `continueIdecoUntil60IfEarlyRetired == true`：允許繼續提繳，金額從 `currentLiquidCash` 扣除，計入年度投資本金與資產累積。
  - 若 `continueIdecoUntil60IfEarlyRetired == false`：維持既有行為，停繳並保留帳戶資產進行複利滾動。
- **稅務抵扣**：
  將退休後產生的iDeCo提繳額，作為 `InvestmentContributions.deductibleContributions()` 傳入稅務計算引擎，若當年度有其他應納稅所得（如已宣告之投資收益），標準折抵其課稅所得。

## 影響範疇與實作評估
- **純擴充、零破壞性**：預設值為 `false`，完全保持既有一百多個模擬測試與一般正常退休流程的100%相容性。
- **實作優先級**：建議排在 [issue-193](../pending%20fix/issue-193.md)（退休當年在職月份拆分修復）與 [issue-194](../pending%20fix/issue-194.md)（企業型DC在職月份拆分修復）落地之後，作為進階FIRE模擬特性單獨排期投入。
